# **App Name**: MoatAnalyzer

## Core Features:

- Google Sign-In: Authenticate users using their Google account via Firebase Authentication.
- Ticker Input: Input field for entering a US stock ticker symbol.
- Moat Analysis Job Creation: When 'Analyze' button is clicked, a new document is created in the 'moat_jobs' collection with fields: uid, ticker, status ('queued'), createdAt.
- Real-time Job Status: The latest job is displayed in the UI by listening to Firestore updates in real-time.
- Moat Rating: Display a qualitative moat rating (e.g., Wide, Narrow, None). This will eventually be generated by AI but currently will show static result
- Moat Summary: Display a short summary of the moat analysis.  This will eventually be generated by AI using an LLM as a tool that decides if particular pieces of info will impact its analysis, but will initially display a canned sentence.

## Style Guidelines:

- Primary color: Deep indigo (#3F51B5) to convey trust and sophistication.
- Background color: Light indigo (#E8EAF6) - a very light tint of the primary color for a calm backdrop.
- Accent color: Violet (#7E57C2), a higher-saturation analogous hue, for interactive elements and emphasis.
- Headline font: 'Space Grotesk', sans-serif. Body text: 'Inter', sans-serif.
- Minimalist icons to represent different aspects of the moat analysis (e.g., a shield for competitive advantage).
- Clean and simple layout with a focus on readability. The ticker input field should be prominent.
- Subtle loading animations while the analysis is in progress.
